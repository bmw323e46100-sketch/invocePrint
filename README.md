# Заявка на отгрузку — настольное приложение на Rust

Однооконное десктоп-приложение для торговой точки. Пользователь вводит
строки товаров (наименование, количество, единица измерения, цена), нажимает
одну кнопку — приложение генерирует готовый PDF-документ «Заявка на отгрузку»
и автоматически открывает его в системном просмотрщике для печати.

Полностью автономно: без веб-сервера, без интернета, без установки рантаймов.
Один `.exe` файл — двойной клик и работает.

## Возможности

- **Нативное окно** на egui/eframe (не Electron, не Tauri, не веб-страница).
- **PDF генерируется средствами Rust** (крейт `genpdf` на базе `printpdf`).
- **Шрифт PT Serif** с поддержкой кириллицы вшит в бинарник через
  `include_bytes!` — никаких внешних шрифтов не требуется.
  Файлы шрифта автоматически скачиваются при первой сборке через `build.rs`
  из репозитория google/fonts (SIL OFL 1.1).
- **Сумма прописью** — полный алгоритм с правилами русского языка:
  - рубли: «рубль / рубля / рублей» (1 рубль, 2 рубля, 5 рублей, 11 рублей, 21 рубль…);
  - тысячи в женском роде: «одна тысяча / две тысячи / пять тысяч»;
  - миллионы: «один миллион рублей»;
  - копейки: «01 копейка / 02 копейки / 05 копеек»;
  - первая буква заглавная.
- **Автосохранение черновика** в JSON рядом с exe. При перезапуске таблица
  восстанавливается; номер и дата при восстановлении генерируются заново.
- **Кнопка «Новая заявка»** стирает черновик и генерирует новый номер.
- **Открытие PDF** в системном просмотрщике через крейт `open`.

## Сборка

### Требования

- Rust stable (edition 2021), рекомендуемая версия 1.74+.
- Для сборки под Windows: MSVC toolchain (`rustup default stable-x86_64-pc-windows-msvc`).
- **Интернет для первой сборки** — `build.rs` скачает шрифты PT Serif (~700 КБ)
  из `cdn.jsdelivr.net`. После этого все последующие сборки работают офлайн.

### Команды

```bash
# Debug-сборка + запуск (при первой сборке скачаются шрифты)
cargo run

# Release-сборка (оптимизация, без консоли на Windows)
cargo build --release

# Юнит- и интеграционные тесты
cargo test

# Пример: сгенерировать sample.pdf из тест-кейса спецификации
cargo run --example gen_sample
```

### Что делать, если сборка падает с «file not found for module»

Эта ошибка возникает, только если у вас в `src/` есть старые файлы
`model.rs`, `fmt.rs`, `money_words.rs`, `pdf.rs`, `gui.rs`. В текущей
версии весь код собран в **один файл `src/lib.rs`** — отдельных модулей
создавать не нужно. Если у вас остались старые файлы модулей — удалите их.

### Что делать, если не скачиваются шрифты

`build.rs` пытается скачать шрифты через PowerShell (`Invoke-WebRequest`)
и через `curl.exe`. Если оба способа не сработали (например, корпоративный
прокси блокирует `cdn.jsdelivr.net`), сделайте так:

1. Скачайте вручную:
   - https://cdn.jsdelivr.net/gh/google/fonts@main/ofl/ptserif/PT_Serif-Web-Regular.ttf
   - https://cdn.jsdelivr.net/gh/google/fonts@main/ofl/ptserif/PT_Serif-Web-Bold.ttf
2. Положите их в папку `assets/fonts/` проекта.
3. Переименуйте в `pt-serif-regular.ttf` и `pt-serif-bold.ttf` соответственно.
4. Запустите `cargo build --release` снова.

### Что делает build.rs

При первой сборке `build.rs` проверяет наличие файлов шрифтов в `assets/fonts/`.
Если их нет — скачивает:

- `pt-serif-regular.ttf` из `https://cdn.jsdelivr.net/gh/google/fonts@main/ofl/ptserif/PT_Serif-Web-Regular.ttf`
- `pt-serif-bold.ttf` из `https://cdn.jsdelivr.net/gh/google/fonts@main/ofl/ptserif/PT_Serif-Web-Bold.ttf`

На Windows используется `Invoke-WebRequest` (PowerShell) или запасной `curl.exe`.
На Linux/macOS — `curl` или `wget`. Если скачивание не удалось, build script
завершится с понятной ошибкой и подсказкой, куда положить файлы вручную.

После первой успешной сборки шрифты остаются в `assets/fonts/`, и больше
интернет для сборки не нужен.

### Где появляется exe

После `cargo build --release`:

- **Linux/macOS**: `target/release/zayavka`
- **Windows**: `target\release\zayavka.exe`

Этот бинарник полностью автономен: шрифты вшиты, зависимостей нет. Можно
скопировать его на любую машину с Windows 10/11 и запустить двойным кликом.

## Использование (3 шага)

1. **Запустите `zayavka.exe`** двойным кликом.
   Откроется окно «Заявка на отгрузку № DZHOДXXXXXX от <дата>» с пустой
   таблицей и одной строкой для ввода.

2. **Заполните строки товаров**:
   - **Товар** — наименование (текст);
   - **кол-во** — количество (число, поддерживает запятую и точку);
   - **ед.** — выбор из выпадающего списка: «шт» или «к-кт»;
   - **цена** — цена за единицу;
   - **сумма** — считается автоматически.
   Когда заполняете последнюю строку, автоматически добавляется новая пустая.
   Чтобы удалить строку — нажмите «×» в её правой части.

3. **Нажмите «Сформировать PDF»**.
   PDF сохранится в подкаталог `Заявки/` рядом с `zayavka.exe` под именем
   `Заявка DZHOДXXXXXX.pdf` и сразу откроется в системном просмотрщике
   (Edge/Chrome/Acrobat — что настроено по умолчанию для PDF). Оттуда
   можно распечатать документ.

Дополнительно:
- **«Новая заявка»** — спросит подтверждение, затем очистит таблицу и
  сгенерирует новый номер (старый черновик стирается).
- **«+ Добавить строку»** — добавляет пустую строку вручную.

## Куда сохраняются файлы

| Что | Куда |
|---|---|
| PDF-документы | `<папка_с_exe>/Заявки/Заявка DZHOДXXXXXX.pdf` |
| Черновик (JSON) | `<папка_с_exe>/zayavka_draft.json` |

Если папка с exe недоступна для записи (например, `Program Files`), приложение
переключается на каталог данных пользователя:

- **Windows**: `%APPDATA%\zayavka\`
- **Linux**: `~/.local/share/zayavka/`
- **macOS**: `~/Library/Application Support/zayavka/`

## Константы документа (зашиты в код)

| Поле | Значение |
|---|---|
| Поставщик | Индивидуальный предприниматель Сюксина Мария Владимировна |
| ИНН | 663004224114 |
| Префикс номера | DZHOД |

## Формат чисел

- Разделитель тысяч — неразрывный пробел (U+00A0).
- Десятичный разделитель — запятая, два знака после запятой.
- Пример: `47 100,00`.
- В полях ввода принимаются и точка, и запятая; пробелы игнорируются.

## Структура PDF

А4 портрет, поля 13/12/15 мм, шрифт PT Serif (10 pt, line-spacing 1.35):

1. По центру, увеличенный размер (13 pt): `Заявка на отгрузку № DZHOДXXXXXX от <дата>`.
   Под ним тонкая линия.
2. `Поставщик:  <название, жирным>` и `ИНН:  <ИНН, жирным>`.
3. Таблица с рамкой, шапка жирная: `№ | Товар | кол-во | ед. | цена | сумма`.
   Числовые колонки по центру/вправо, «Товар» — влево с переносом строк.
   Последняя строка: `Итого:` и итоговая сумма (жирным).
4. `Всего наименований N, на сумму X руб.` (X округлён до целого рубля).
5. Сумма прописью — жирным.
6. Тонкая линия; `Оплата`; `    Наличные <сумма>`; `    Сдача  0,00`;
   тонкая линия.
7. `Кассир:  __________________________________` и мелким `                  (подпись)`.

## Тест-кейс приёмки

Ввести три строки:

| Товар | кол-во | ед. | цена |
|---|---|---|---|
| Поршнекомплект с кольцами G4FA +0.5 | 1 | к-кт | 9100 |
| Антифриз, Korea-Standard зелёный -37°C, 5кг | 1 | шт | 1780 |
| HYUNDAI/KIA/MOBIS Клапан выпускной | 8 | шт | 190 |

Ожидаемый результат:
- Суммы строк: 9 100,00 / 1 780,00 / 1 520,00.
- Итого: **12 400,00**.
- Всего наименований **3**, на сумму **12 400 руб.**
- Прописью: **Двенадцать тысяч четыреста рублей 00 копеек**.
- Оплата / Наличные **12 400,00**, Сдача **0,00**.

Все эти значения проверяются юнит- и интеграционными тестами (`cargo test`).

## Проверка автономности

Приложение:

- Не открывает сетевых портов.
- Не делает HTTP/HTTPS запросов.

при запуске (`netstat`, `tcpview`, Wireshark).
