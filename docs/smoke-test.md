# Чек-лист ручного smoke-теста

Применяется **после каждой итерации** перед merge в `main`.

## Подготовка

- [ ] Сборка прошла: `cargo build --release`
- [ ] `cargo test` зелёный (включая snapshot-тест PDF)
- [ ] Удалить старый черновик рядом с `zayavka.exe` (`zayavka_draft.json`,
      папка `Заявки/`, папка `История/`)

## 1. Запуск и базовое окно
- [ ] Двойной клик по `zayavka.exe` — приложение открывается без ошибок
- [ ] Заголовок окна: `Заявка на отгрузку № DZHOДXXXXXX от <сегодня>`
- [ ] Светлая тема по умолчанию

## 2. Ввод данных
- [ ] Ввести «Товар A», кол-во «1», ед. «шт», цена «100» → сумма «100,00»
- [ ] При заполнении последней строки появляется новая пустая
- [ ] Кнопка «×» удаляет строку

## 3. Итоговая панель
- [ ] «Итого:» показывает сумму всех строк
- [ ] «Сумма прописью:» корректная

## 4. Сохранение и восстановление черновика
- [ ] Ввести 2–3 строки, закрыть приложение
- [ ] Файл `zayavka_draft.json` создан
- [ ] Запустить повторно — строки восстановлены, **номер заявки и дата — новые**

## 5. Новая заявка
- [ ] Нажать «Новая заявка» → диалог подтверждения
- [ ] Подтвердить — таблица очищена, номер новый

## 6. Сформировать PDF
- [ ] Ввести тест-кейс (2500+1400+9100 = 13 000)
- [ ] Нажать «Сформировать PDF»
- [ ] PDF открылся в просмотрщике
- [ ] Содержимое: заголовок, «Поставщик: ООО «Автоконтракты»» (без ИНН),
      таблица с 3 строками, «Итого: 13 000,00», прописью, графы «Отпустил»/«Получил»

## 7. История
- [ ] Нажать «История» → открывается окно
- [ ] Список содержит только что созданную заявку
- [ ] Кликнуть на неё → справа открываются детали
- [ ] «Открыть PDF» открывает тот же PDF
- [ ] «Удалить из истории» — запись исчезает

## 8. Импорт из буфера
- [ ] Скопировать CSV из спецификации в буфер
- [ ] Нажать «Вставить из буфера»
- [ ] Строки добавились

## 9. Копировать текст
- [ ] Нажать «Копировать текст»
- [ ] Вставить в Блокнот — читаемый список товаров с итогом

## 10. Тёмная тема
- [ ] Нажать «Тёмная тема» → переключается
- [ ] Нажать «Светлая тема» → возврат
- [ ] Тема не «слетает» между кадрами

## 11. Закрытие
- [ ] Закрыть окно — приложение завершается без ошибок
- [ ] Черновик сохранён

## Регрессионные сценарии (при крупных итерациях)
- [ ] 100 строк товаров — приложение не тормозит
- [ ] 500 записей в истории — окно открывается < 1 сек
- [ ] Длинное наименование (200+ символов) — перенос в PDF
- [ ] Сумма > 1 000 000 руб. — форматирование работает
- [ ] Спецсимволы (`|`, `/`, `±`, `°C`, `«»`) — корректно в PDF
- [ ] Эмодзи в наименовании — фильтруются
